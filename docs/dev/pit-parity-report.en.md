## 2. Parity caliber

Three independent verdicts cross-check each point; any disagreement is
recorded as a difference and root-caused:

1. **PIT official status**: the real per-point verdicts of PITest 1.19.6 in
   the committed artifact `kernel/mutation/testdata/pit/pit-mutations.json`.
2. **Abate engine verdict**: the verdicts produced by the real
   `kernel/mutation` engine (`NewRegistryWith` + `NewEngineWithRegistry` +
   `Engine.Run`) on the isomorphic fixture.
3. **Semantic witness**: an independent judgment, per the semantics of the
   Java baseline project, of whether the mutation is distinguishable within
   the suite. This judgment does not look at PIT status and is used to
   cross-check that the mapping table was not reverse-fitted to the results.

Status-mapping caliber:

- PIT `KILLED` ↔ Abate `KILLED`;
- PIT `SURVIVED` with the semantic witness judging it indistinguishable
  within the suite ↔ Abate `EQUIVALENT` (the Abate fixture carries
  semantically equivalent mutations explicitly on `h-equivalent` nodes);
- PIT `NO_COVERAGE` ↔ Abate coverage count 0 and not killed, i.e. `SURVIVED`
  (the Abate fixture carries uncovered mutations explicitly on
  `j-survived` nodes).

## 6. Honest boundary statement

1. **No JVM was started**: this parity round does not replay the PIT
   process; it uses the committed official real-run artifacts
   (`pit-mutations.json` / `pit-mutations.xml` / `pit-console-report.txt`);
   only `scripts/pit-parity.sh --rerun-pit` actually re-runs PITest.
2. **The baseline project's coverage is limited**: the PIT baseline project
   has one class, three tests, and ten methods; 28 mutations cover seven
   operator families, which is not the full PITest operator-family set.
3. **The mapping table is not a one-to-one cover**: 7 PIT mutations land on
   operator families for which Abate's seven operator classes have no
   semantics (ordering-check removal, string-return emptying); each is
   registered as an exclusion.
4. **The semantic-equivalence caliber**: PITest does not recognize
   semantically equivalent mutations and reports only `SURVIVED`; the
   equivalence conclusions in this report come from the semantic witness,
   with the mapping caliber stated in section 2.
5. **Fixture isomorphism**: the Abate-side fixture is isomorphic to the
   fixture in `kernel/mutation/helpers_test.go` (ten nodes, seven operator
   classes, three branches: equivalent/timeout/uncovered); if either side's
   fixture drifts, that side's unit tests fail first.
