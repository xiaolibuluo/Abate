## 2. Regression caliber

Three independent verdicts cross-check each point; any disagreement is
recorded as a difference and root-caused:

1. **Frozen expected classification**: derived by the semantic witness in the
   self-developed golden, not an external engine's real-run result.
2. **Abate engine verdict**: the verdicts produced by the real
   `kernel/mutation` engine (`NewRegistryWith` + `NewEngineWithRegistry` +
   `Engine.Run`) on the isomorphic fixture.
3. **Semantic witness**: an independent judgment, per the self-developed
   baseline semantics, of whether the mutation is distinguishable within the
   suite. This judgment does not look at the frozen expectation and is used
   to cross-check that the mapping table was not reverse-fitted to the results.

Status-mapping caliber:

- Expectation `KILLED` ↔ Abate `KILLED`;
- Expectation `SURVIVED` with the semantic witness judging it indistinguishable
  within the suite ↔ Abate `EQUIVALENT` (the self-developed fixture carries
  semantically equivalent mutations explicitly on `h-equivalent` nodes);
- Expectation `NO_COVERAGE` ↔ Abate coverage count 0 and not killed, i.e.
  `SURVIVED` (the self-developed fixture carries uncovered mutations
  explicitly on `j-survived` nodes).

## 6. Honest boundary statement

1. **No external engine was started**: this regression neither replays any
   third-party tool nor reads any upstream artifact; it compares this
   repository's engine output against the frozen self-developed golden.
2. **Competitor comparison score is NOT_MEASURED**: all upstream artifacts
   have been removed; no official comparison rate is claimed.
3. **The mapping table is not a one-to-one cover**: 7 cases land on operator
   families for which Abate's seven operator classes have no semantics
   (ordering-check removal, string-return emptying); each is registered as an
   exclusion.
4. **Semantic equivalence is given by the witness**: this repository's engine
   recognizes semantically equivalent mutations, and the equivalence
   conclusion is cross-checked by the independent witness.
5. **Fixture isomorphism**: the Abate-side fixture is isomorphic to the
   fixture in `kernel/mutation/helpers_test.go` (ten nodes, seven operator
   classes, three branches: equivalent/timeout/uncovered); if either side's
   fixture drifts, that side's unit tests fail first.
