## 1. 安全架构

```
Android Keystore (密钥存储)
  |
  +-- API Key 加密存储
  +-- 模型配置加密
  +-- 签名密钥保护
  |
WASM Sandbox (代码隔离)
  |
  +-- 工具执行沙箱
  +-- 文件系统越权防护
  +-- 内存/CPU 配额限制
  +-- 网络白名单
  |
Permission Matrix (权限强制)
  |
  +-- Agent 工具调用校验
  +-- 审计日志全记录
  +-- 安全部独立审计
  |
Zero Telemetry (零遥测)
  |
  +-- 全部数据本地存储
  +-- 零上传零收集
  +-- 无分析 SDK
```

## 2. 安全措施

| 层面 | 措施 | 实现方式 |
|------|------|----------|
| 密钥存储 | API Key 加密 | Android Keystore + AES-256 |
| 代码执行 | WASM 沙箱隔离 | wazero 移植，禁止越权 |
| 网络访问 | 端点白名单 | 仅模型 API 域名，无其他 |
| 本地模型 | 沙箱加载 | 限制内存/CPU，隔离推理 |
| Agent 权限 | 权限矩阵 | 强制校验 + 审计日志 |
| 用户数据 | 全本地 | Room + DataStore，零上传 |
| 代码签名 | 签名隔离 | 签名密钥仅构建/发布 Agent |
| 审计日志 | 不可篡改 | Room 存储，仅追加模式 |

## 3. 隐私合规

| 法规 | 要求 | 实现 |
|------|------|------|
| GDPR | 数据最小化、用户控制 | 零数据收集，全部本地 |
| CCPA | 知情权、删除权 | 无数据上传，删除=卸载 |
| Android 12+ | 数据安全标签 | 无数据共享，无加密传输 |

## 4. 安全 Agent 职责

| 角色 | 职责 | 触发时机 |
|------|------|----------|
| 审计 Agent | 代码安全扫描、权限审查 | 每次代码生成后 |
| 沙箱 Agent | WASM 沙箱完整性验证 | 应用启动时 |
| 隐私 Agent | 合规检查、数据流审计 | 发布前强制 |

## 5. 安全红线

1. 禁止任何网络请求非模型 API 端点
2. 禁止 Agent 直接访问文件系统（必须通过沙箱）
3. 禁止明文存储 API Key
4. 禁止安全 Agent 执行写操作
5. 禁止绕过权限矩阵调用工具
6. 禁止上传任何用户数据到远程服务器
7. 禁止集成任何分析/统计 SDK
