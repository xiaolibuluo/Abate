## 1. 文档目的与范围

本文档回答四个问题：

1. Abate 一共要建哪些模块（全量模块地图，禁止遗漏）。
2. 模块之间谁依赖谁（依赖图，禁止循环依赖）。
3. 按什么顺序建（M0-M6 里程碑，每阶段有明确验收标准与退出条件）。
4. 什么叫做完了（验收总则：DoD、覆盖率、性能预算、确定性、安全、文档）。

范围：Abate 引擎全部 L0-L7 层与横切关注点。不含：官网运营、社区运营流程（另立文档）。

## 2. 总体目标与成功判据

总体目标：建成混沌测试与变异测试一体化的确定性引擎，内核十年不大更新、每年仅简单维护，生态小时级扩展。

成功判据（可量化）：

1. 同一种子同配置，任意次运行结果逐字节一致（确定性回放校验通过率 100%）。
2. 内核（L0-L3）对外部网络零依赖：断网环境全量测试套件通过。
3. 七语言官方规范规则集全部落地，Abate 仓库自身 100% 通过自研检查器检查（吃自己的狗粮）。
4. 插件从签名到热加载上线全流程小于 1 小时（生态小时级）。
5. 内核 API 年度破坏性变更为 0（TCK 全绿）。

## 4. 依赖关系图

```
CTL-CLI / CTL-REST / CTL-WEB（L7）
        │ 依赖
        ▼
ADP-* / RPT-*（L5/L6，经 WAS-HOST 加载）
        │ 依赖
        ▼
LNG-*（L4：AIR → 规则/检查/算子派生）
        │ 依赖
        ▼
CES-*（L2）──► KRN-ALG/SCH/OBS/VER（L0）◄── SIM-*（L3）
                    │ 内含
                    ▼
              KRN-MUT / KRN-INJ（L0 内核自有）
```

依赖铁律：

1. 依赖只允许自上而下、自外而内；L0 不 import L1-L7 任何包。
2. 禁止循环依赖：CI 门禁 depguard 强制（.golangci.yml 已启用）。
3. L0 仅依赖 Go 标准库与源码级并入的自有代码（十年内核铁律）。
4. WAS-HOST 是 L4-L7 插件进入内核的唯一通道（端口-适配器）。

## 5. 阶段与里程碑规划

### M0（已完成）：奠基

- 交付：仓库骨架、五段门禁（gofmt→vet→golangci-lint→test -race→build）、CI workflow、架构总纲。
- 验收：门禁全绿；桩代码注入实测被拦截（godox/unused 命中即 FAIL）。

### M1：内核最小闭环（确定性实验跑通）

- 目标：单进程内跑通一个确定性 HPOV 实验（无语言前端、无 WASM）。
- 交付：KRN-ALG、KRN-SCH、KRN-OBS、KRN-VER、CES-SCHEMA/PARSE/VALID、SIM-CLK、SIM-RNG、CTL-CLI 最小集。
- 验收标准：
  1. 一份 CES YAML 声明稳态+扰动+探针，CLI 执行后输出确定性报告。
  2. 同种子运行 100 次，报告逐字节一致（哈希校验）。
  3. 扰动代数单测覆盖四运算全部代数律（结合律/单位元/对偶补偿）。
  4. 内核包（L0/L2/L3）测试覆盖率语句 ≥95%、分支 ≥85%。
- 退出条件：全部验收项通过且门禁全绿。

### M2：模拟器完备 + 双核并入

- 目标：确定性模拟器全量 + PIT/chaosblade 源码级并入完成。
- 交付：SIM-NET/FS/SCHED/REC、KRN-MUT、KRN-INJ、XCU-PRF 基准套件。
- 验收标准：
  1. 虚拟网络四类故障（延迟/分区/丢包/限带宽）在模拟器内可注入且确定性回放一致。
  2. PIT 对拍：同一变异点集合，Abate 移植算子与 PIT 参考实现结果一致率 100%（对拍报告入库）。
  3. chaosblade 并入后：原 CLI 外壳移除，库形态 API 通过内核 TCK；上游安全补丁回移流程演练一次。
  4. 性能预算首测：调度器单实验开销、模拟器事件吞吐达标（数值见 08 分册性能预算表）。

### M3：Go 语言前端闭环（吃自己的狗粮）

- 目标：LNG-AIR+LNG-GO+LNG-RULE+LNG-CHK+LNG-MUT 全量，Abate 仓库自检。
- 验收标准：
  1. AIR 序列化 schema 版本化，跨版本兼容测试通过。
  2. Go 官方规范规则集（Effective Go+CodeReviewComments+vet 语义子集）≥100 条规则落地。
  3. Abate 仓库经自研检查器检查 0 违规（与 golangci-lint 结果对拍，差异逐条说明）。
  4. 规则→算子派生：至少 20 条规则自动派生 M 族算子并在变异实验中可用。

### M4：WASM 运行时 + 生态最小闭环

- 目标：插件体系跑通（operator/reporter/adapter 三类各至少 1 个官方插件）。
- 验收标准：
  1. 未签名插件加载被拒；能力越权调用被沙箱拦截（安全测试用例）。
  2. 热加载：替换插件版本，运行中实验不中断、旧实例排空后卸载。
  3. 插件从提交到发布全流程 ≤1 小时（CI 实测记录）。
  4. RPT-SARIF 输出通过 SARIF 官方校验器。

### M5：七语言全量 + 控制面

- 目标：LNG-PY/JS/C/RS/CS/KT 全部落地；CTL-REST 上线。
- 验收标准：
  1. 每语言前端解析吞吐与 AIR 保真度达标（每语言基准用例集 100% 通过）。
  2. 每语言官方规范规则集 ≥60 条，检查器输出 SARIF。
  3. REST API OpenAPI 文档生成且与实现一致性测试通过。

### M6：GA

- 目标：质量、安全、文档、发布全达标。
- 验收标准：
  1. CES-TCK 发布，第三方实现走通合规流程（至少 1 个示例实现）。
  2. 安全审计：签名链、沙箱逃逸测试、依赖漏洞扫描全绿。
  3. XCU-REL：GPG 签名发布流程演练（tag+资产+校验和+SBOM）。
  4. 全量文档：用户指南/开发指南/规范文本/ADR 全部就位。

## 6. 验收总则（所有模块通用 DoD）

一个模块叫做完成，必须同时满足：

1. 代码：合入 main 且五段门禁全绿；无 TODO/FIXME（godox 拦截）；版权头+水印齐全。
2. 测试：单元测试（表驱动，覆盖正常/边界/错误三类路径）+ 集成测试 + 确定性回放测试（同种子双跑哈希一致）。覆盖率：内核 ≥95%/85%（语句/分支），生态层 ≥85%/75%。
3. 接口：对外 API 有 Go doc 注释（godot 强制句号结尾）；破坏性变更走 ADR+2 版本废弃窗口。
4. 文档：模块 README（职责/接口/验收清单）+ CHANGELOG 条目。
5. 性能：涉及热路径的模块附基准测试，且不超性能预算（08 分册）。
6. 安全：新依赖必须源码级并入（五步并入法）并记录来源 commit 哈希与许可证审查结论。

测试金字塔：单元 70% / 集成 20% / 端到端 10%；另加对拍测试（PIT/上游引擎）、模糊测试（解析器与 CES 输入）、混沌自测（Abate 对自身运行混沌实验）。

## 7. 风险登记册

| 编号 | 风险 | 等级 | 缓解措施 |
|---|---|---|---|
| R1 | PIT 为 Java 实现，与 Go 内核存在语言鸿沟 | 高 | PIT 定位为算法参考+对拍基准：vendor 源码入 third_party/pit（只读参考），核心算法（算子族/覆盖率调度/最小化）Go 源码级移植入 KRN-MUT，逐算子对拍验证一致率 100%；Abate 变异作用在 AIR 源码层而非 JVM 字节码层，架构上不需要运行时依赖 JVM |
| R2 | chaosblade 上游演进分叉 | 中 | 并入即冻结基线；上游安全补丁评审回移；内核 TCK 锁定行为 |
| R3 | WASM 生态接口不稳定（WASI Preview2 演进） | 中 | WIT 接口版本化+兼容矩阵；宿主层隔离 WASI 细节 |
| R4 | 七语言前端工作量超预期 | 高 | M3 先 Go 闭环验证架构，其余语言按 M5 并行分批；前端只做解析复用，规则全部自研共享 AIR 层 |
| R5 | 确定性被并发破坏 | 高 | 全内核单线程虚拟时钟驱动；真实并发只存在于模拟器边界且事件序号全序化；-race 门禁+回放哈希校验双保险 |
| R6 | AGPLv3 生态接受度 | 中 | 双授权（商业授权）+ CES 开放规范降低接入门槛 |
