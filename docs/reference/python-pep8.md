# Python 官方规范规则（PEP 8）— 归档参考

> 来源：https://peps.python.org/pep-0008/ （官方，M5 规则引擎落地依据）
> 归档日期：2026-11-08

## 命名
- 禁用 `l`/`O`/`I` 单字符变量名。
- 包/模块：短名全小写（模块可含下划线）；类名 `CapWords`；异常加 `Error` 后缀。
- 函数/变量：全小写+下划线；常量全大写+下划线。
- 方法首参 `self`，类方法 `cls`；与关键字冲突加尾随下划线。

## 缩进
- 每级 4 空格；空格为首选，禁止混用 tab/space；悬挂缩进。

## 行长度
- 代码 ≤79 字符；注释/docstring ≤72；团队可放宽至 99。

## 导入
- 单行单导；文件顶部；分组：标准库→第三方→本地；避免 `import *`。

## 空格
- 二元运算符两侧 1 空格；函数调用 `spam(1)` 括号前无空格；切片冒号等量空格；禁止尾随空格；禁止同一行多语句。

## 注释 / Docstring
- 注释与代码矛盾则更新；块注释同缩进；docstring 遵循 PEP 257（模块/函数/类/方法必须）。

## 函数
- 顶层函数/类前后 2 空行；类内方法 1 空行；用 `def` 而非绑定 lambda。
- 比较：单例用 `is`/`is not`；类型检查用 `isinstance()`；空序列用 `if not seq:`。
