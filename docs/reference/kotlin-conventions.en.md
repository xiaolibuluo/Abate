# Kotlin Official Standards Rules (Kotlin Coding Conventions) — Abstract

**Abstract-only companion**: the full Chinese text is in
[`kotlin-conventions.md`](kotlin-conventions.md). External-specification
links are preserved as-is; no external-standard content is rewritten in this
file.

## Scope

This archived reference records the official Kotlin Coding Conventions as the
baseline for the M5 Kotlin frontend rule engine. It condenses naming
(UpperCamelCase types, camelCase functions, backtick test names, acronym
casing rules, backing properties), formatting (4-space indent, brace
placement, operator/colon spacing rules), source-file organization
(one class per file, descriptive names, declaration order inside classes),
lambda layout, and companion-object placement.
