# JS/TS Community Standards Rules (Airbnb JavaScript Style Guide) — Abstract

**Abstract-only companion**: the full Chinese text is in
[`js-airbnb.md`](js-airbnb.md). External-specification links are preserved
as-is; no external-standard content is rewritten in this file.

## Scope

This archived reference records the Airbnb JavaScript Style Guide as the
community baseline for the M5 JS/TS frontend rule engine. It condenses the
guide's sections: variable declaration (`const` first, no `var`, no chained
assignment), object/array literals and spread copying, strings (single quotes,
template literals, no `eval`), functions and arrow functions, classes and ES
Modules (no wildcard imports, no mutable exports), iterator methods
(`map`/`filter`/`reduce` over `for-in`/`for-of`), and the closing
Always/Never quick list.
