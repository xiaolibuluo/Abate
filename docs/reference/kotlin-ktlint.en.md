# Kotlin Community Standards Rules (ktlint Standard Ruleset) — Abstract

**Abstract-only companion**: the full Chinese text is in
[`kotlin-ktlint.md`](kotlin-ktlint.md). External-specification links are
preserved as-is; no external-standard content is rewritten in this file.

## Scope

This archived reference records the ktlint standard ruleset as the community
baseline for the M5 Kotlin frontend rule engine. It lists the baseline rule
ids (naming, `indentation`, spacing around keywords/operators/commas,
`import-ordering`, `no-unused-imports`, `no-wildcard-imports`,
`modifier-order`, `string-template`, `range-spacing`, etc.), the experimental
signature rules to enable with caution, and the mapping note: at M5
integration time, ktlint official rule ids are mapped to AIR pattern matching.
