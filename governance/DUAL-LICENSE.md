# 双授权说明（XCU-GOV）

> 对应 PLAN-08 XCU-GOV §6。Abate 采用 **AGPLv3（开源侧）+ 商业授权（闭源侧）**
> 双授权模式。

## 1. 为什么双授权

- **AGPLv3（开源侧）**：网络/SaaS 场景下强 copyleft，保障社区与用户自由，
  避免 SaaS 规避。适合自托管、研究、贡献。
- **商业授权（闭源侧）**：允许不公开衍生代码的闭源集成，降低企业合规门槛，
  联系 **xiaolibuluo@163.com** 获取商业许可。

两条授权并存：你可选择 AGPLv3 义务，或购买商业授权免除其 copyleft 义务。

## 2. 贡献者协议

- **CLA（贡献者许可协议）**：可选。签署后明确授予项目使用与再许可权利。
- **DCO（开发者证书）**：强制。每次提交须 `Signed-off-by`（`git commit -s`），
  声明贡献者有权提交且同意 DCO 1.1。
- 贡献即授予双授权权利：项目可在 AGPLv3 与商业授权下使用你的贡献。

## 3. 许可证兼容性（导入依赖）

- 仅允许：MIT / Apache-2.0 / BSD / ISC / CC0 / Unlicense / Public Domain。
- 拒绝：GPL-2.0 / GPL-3.0 / LGPL / AGPL（任何变体）—— 与 AGPLv3 传染性冲突。
- 审查流程见 `governance/THIRD-PARTY.md` 与 `third_party/LICENSE-MANIFEST.md`。

## 4. 商标与水印

- 『小黎的部落』为项目数字水印与品牌标识，不构成独立商标授权。
- 版权头水印随源码分发，详见 `governance/HEADERS.md`。
